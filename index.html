00. Nextra v4 基准总览

Nextra v4 静态网站生成基准实测

本站点由独立仓库 page2401/nextra 构建，基于主仓库 page2401.github.io/docs/ 的标准 GFM 原始母版派生适配而来，用于量化 Nextra v4 (4.6.1) 在 Next.js App Router（RSC）架构、<Callout> 组件与 GFM Alerts 双轨渲染、内置 Mermaid 图表、内置 KaTeX 公式以及 _meta.js 编程式导航上的真实工程表现。

五大基准测试章节导航

章节路径测试维度Nextra v4 (4.6.1) 核心实测特征
01. 专属标注与元数据专属标注与 MDX 3 边界内置 <Callout> JSX 组件；withGitHubAlert 要求 > [!NOTE] 后必须跟空引用行 > 才转换，母版紧邻写法会退化为普通引用；format: 'detect' 按后缀区分 .md 与 .mdx
02. 流程图与时序图流程图与时序图内置 @theguild/remark-mermaid@0.3.0（锁在 mermaid@11.17.2），零插件自动接管代码块并随明暗主题重绘
03. 数学公式排版数学公式排版nextra({ latex: true }) 一键启用 remark-math@6 + rehype-katex@7，配合本地打包 katex@0.16.47 样式与字体（零外部 CDN 请求）
04. 目录结构与路由取舍目录结构与 _meta.jscontent/ 内容目录 + app/[[...mdxPath]]/page.jsx 路由解耦；废弃旧版 _meta.json，全面改用 Zod 强校验 _meta.js 编排中文分组与 asIndexPage
05. 高阶代码块与语法高亮rehype-pretty-code 与 <Tabs>专属 filename="..." 标题栏属性与 {3,7-9} 行区间高亮；默认未预装 transformerNotationDiff；多语言组使用 nextra/components <Tabs>
